A structured collection of my **C programming practice, problem-solving exercises, and implementations**.

This repository documents my journey of learning C programming from the fundamentals to more advanced concepts such as **arrays, functions, pointers, recursion, strings, sorting, and problem-solving**.

# 🛠️ How to Run

## 1. Install GCC

Check whether GCC is installed:

```bash
gcc --version
```

If GCC is not installed on Ubuntu:

```bash
sudo apt update
sudo apt install build-essential
```

---

## 2. Compile a C Program

```bash
gcc filename.c -o output
```

---

## 3. Run the Program

```bash
./output
```

### Example

```bash
gcc strings/reverse_string.c -o reverse
./reverse
```

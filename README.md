# C Programming Practice

Doing my C programming and GitHub practice in this repository.

## How to Run

Install GCC and verify the installation:

```bash
gcc --version
```

Compile a C program:

```bash
gcc filename.c -o output
./output
```

## Compiler and Operating System

- GCC Compiler: 13.3.0
- Linux: Ubuntu 24.04.4 LTS
- Windows 11

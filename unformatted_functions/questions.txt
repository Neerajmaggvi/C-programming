========================================
       C UNFORMATTED I/O PRACTICE
========================================

Functions to Practice:
1. getchar()
2. putchar()
3. fgets()
4. puts()


QUESTION 1: Read and Print a Character
---------------------------------------
Write a C program that:
- Asks the user to enter one character.
- Reads the character using getchar().
- Prints the character using putchar().

Example:
Enter a character: A
You entered: A


QUESTION 2: Character and ASCII Value
--------------------------------------
Write a C program that:
- Reads one character using getchar().
- Prints the character.
- Prints its ASCII value.

Example:
Enter a character: A
Character: A
ASCII: 65


QUESTION 3: Print Using putchar()
---------------------------------
Write a C program to print:

HELLO

using only putchar() for printing the characters.

Do not use printf() to print HELLO.


QUESTION 4: Read and Print a Name
----------------------------------
Write a C program that:
- Creates a character array of size 30.
- Takes the user's name using fgets().
- Prints the name using puts().

Example:
Enter your name: Neeraj Maggavi
Your name is: Neeraj Maggavi


QUESTION 5: Read a Full Name with Spaces
-----------------------------------------
Write a C program that:
- Takes the user's full name using fgets().
- Prints it using puts().
- The name may contain spaces.

Example:
Enter your full name: Neeraj Maggavi
You entered: Neeraj Maggavi


QUESTION 6: Read and Print a Sentence
--------------------------------------
Write a C program that:
- Creates a character array of size 100.
- Reads a complete sentence using fgets().
- Prints the sentence using puts().

Example:
Enter a sentence: I am learning C programming
You entered: I am learning C programming


QUESTION 7: Count Characters Without strlen()
------------------------------------------------
Write a C program that:
- Reads a sentence using fgets().
- Counts the number of characters using a loop.
- Do not use strlen().
- Print the total number of characters.

Example:
Enter a sentence: Hello World
Number of characters: 11


QUESTION 8: Print a String Character by Character
------------------------------------------------
Write a C program that:
- Reads a string using fgets().
- Prints each character on a separate line using putchar().

Example:
Enter a string: Neeraj

Output:
N
e
e
r
a
j
